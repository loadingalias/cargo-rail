# ripgrep + cargo-rail

**Repo:** <https://github.com/BurntSushi/ripgrep>
**Commit:** `cd1f981` (2025-11-29)

## Demo

![ripgrep demo](./demo.gif)

## Commands

```bash
# Clone and enter
git clone https://github.com/BurntSushi/ripgrep
cd ripgrep

# Initialize cargo-rail
cargo rail init

# Check and apply unification
cargo rail unify --check
cargo rail unify
```

## Impact Summary

| Metric | Value |
|--------|-------|
| Workspace members | **10** (not 1!) |
| Dependencies unified | 9 |
| Member edits | 35 |
| Transitives pinned | 5 |

**Dependencies unified:** serde_json, regex, serde, bstr, memchr, termcolor, globset, walkdir, log

## Configuration

```toml
# .config/rail.toml (generated by cargo rail init)
[unify]
pin_transitives = false  # No workspace-hack
msrv = true
detect_unused = true
```
