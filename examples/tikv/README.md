## Commands

```bash
# Clone and enter
git clone https://github.com/tikv/tikv
cd tikv

# Initialize cargo-rail
cargo rail init

# Check and apply unification
cargo rail unify --check
cargo rail unify
```

## Configuration

```toml
# .config/rail.toml (generated by cargo rail init)
[unify]
pin_transitives = false
msrv = true
detect_unused = true
```

**Note:** tikv has multiple major versions of uuid, semver, derive_more, and nom. cargo-rail automatically detects and skips these with warnings:

```
[WARN] uuid: Multiple major versions detected (majors: 0, 1) - skipping unification.
[WARN] semver: Multiple major versions detected (majors: 0, 1) - skipping unification.
```
