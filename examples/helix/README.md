## Commands

```bash
# Clone and enter
git clone https://github.com/helix-editor/helix
cd helix

# Initialize cargo-rail
cargo rail init

# Check unification
cargo rail unify --check
cargo rail unify

# See affected crates (main demo)
cargo rail affected --since HEAD~10

# Run tests only for affected
cargo rail test --since HEAD~10
```

## Configuration

```toml
# .config/rail.toml (generated by cargo rail init)
[unify]
include_paths = true
include_renamed = false
pin_transitives = true
transitive_host = "root"
exclude = []
include = []
msrv = false
strict_version_compat = true
exact_pin_handling = "warn"
detect_unused = false
```
