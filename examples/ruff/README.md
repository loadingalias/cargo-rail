## Commands

```bash
# Clone and enter
git clone https://github.com/astral-sh/ruff
cd ruff

# Initialize cargo-rail
cargo rail init

# See affected crates (main use case)
cargo rail affected --since HEAD~5

# Run tests only for affected
cargo rail test --since HEAD~5
```
