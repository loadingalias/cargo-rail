![iced demo](./demo.gif)

## Commands

```bash
# Clone and enter
git clone https://github.com/iced-rs/iced
cd iced

# Initialize cargo-rail
cargo rail init

# Check and apply unification
cargo rail unify --check
cargo rail unify
```

## Configuration

```toml
# .config/rail.toml (generated by cargo rail init)
[unify]
include_paths = true
include_renamed = false
pin_transitives = true
transitive_host = "root"
exclude = []
include = []
msrv = false
strict_version_compat = true
exact_pin_handling = "warn"
detect_unused = false
```
