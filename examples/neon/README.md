## Commands

```bash
# Clone and enter
git clone https://github.com/neondatabase/neon
cd neon

# Initialize cargo-rail
cargo rail init

# Check and apply unification
cargo rail unify --check
cargo rail unify

# See affected crates
cargo rail affected --since HEAD~5
```

## Configuration

```toml
# .config/rail.toml (generated by cargo rail init)
[unify]
include_paths = true
include_renamed = true
pin_transitives = true  # Replaces cargo-hakari / workspace_hack
transitive_host = "root"
exclude = []
include = []
msrv = true
strict_version_compat = true
exact_pin_handling = "warn"
detect_unused = true
```

## Notes

- Neon: Serverless Postgres
- Large workspace (48 crates)
- **Uses cargo-hakari** - `pin_transitives = true` replaces the workspace_hack crate
- MSRV detection enabled
