## Commands

```bash
# Clone and enter
git clone https://github.com/meilisearch/meilisearch
cd meilisearch

# Initialize cargo-rail
cargo rail init

# Check and apply unification
cargo rail unify --check
cargo rail unify

# See affected crates
cargo rail affected --since HEAD~5
```
