![tokio demo](./demo.gif)

## Commands

```bash
# Clone and enter
git clone https://github.com/tokio-rs/tokio
cd tokio

# Initialize cargo-rail
cargo rail init

# Check what would be unified
cargo rail unify --check

# Apply unification
cargo rail unify

# See affected crates
cargo rail affected --since HEAD~5
```

## Configuration

```toml
# .config/rail.toml (generated by cargo rail init)
[unify]
include_paths = true
include_renamed = false
pin_transitives = true
transitive_host = "root"
exclude = []
include = []
msrv = false
strict_version_compat = true
exact_pin_handling = "warn"
detect_unused = false
```
